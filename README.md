# Задача продвинутого уровня: Динамическое ценообразование авиабилетов

Калькулятор спроса на авиабилеты для кейса «Решись Авиа». Выберите направление,
дату и цену — приложение покажет число мест, медианный спрос, прогноз продаж
и график девяти квантилей. Расчёт выполняет FastAPI, интерфейс написан на Angular 18.

В комплекте есть сезонный прогноз для пяти направлений из Москвы —
Сочи, Санкт-Петербург, Калининград, Новосибирск и Минеральные Воды.
Доступны даты с 1 июня по 1 июля 2026 года включительно, всего 155 рейсов.

## Запуск на Windows

Нужны Python 3.11+ и Node.js с npm. Поддерживаемые текущей версией Angular CLI
версии Node.js — 18.19.1+ в ветке 18, 20.11.1+ в ветке 20 или 22+.

Откройте PowerShell в корне репозитория, рядом с requirements.txt.
Установите зависимости, соберите интерфейс и запустите сервер.

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt

Set-Location frontend
npm ci
npm run build
Set-Location ..

.\.venv\Scripts\python.exe -m uvicorn backend.main:app
```

Приложение откроется на [127.0.0.1:8000](http://127.0.0.1:8000).
Для повторного запуска достаточно последней команды. После изменения
frontend нужно снова выполнить npm run build.

## Разработка интерфейса

После установки зависимостей запустите backend с перезагрузкой при изменении
Python-файлов.

```powershell
.\.venv\Scripts\python.exe -m uvicorn backend.main:app --reload
```

Во втором терминале из корня репозитория запустите Angular.

```powershell
Set-Location frontend
npm start
```

Откройте [localhost:4200](http://localhost:4200). Запросы /flights и /predict
проксируются на FastAPI по адресу 127.0.0.1:8000. Изменения интерфейса
подхватываются автоматически.

## Расчёт и API

GET /flights возвращает доступные маршруты, даты, базовые цены и имя файла
прогноза. POST /predict принимает маршрут, дату и цену в рублях.

```json
{
  "route": "MOW-AER",
  "date": "2026-06-12",
  "price": 9000
}
```

Для этого запроса на комплектном прогнозе ответ содержит 900 мест,
медианный спрос 970 и прогноз продаж 900. При цене 9 100 ₽ спрос равен 955,9.
Базовая цена маршрута — 9 000 ₽.

Для каждого квантиля q от 0.1 до 0.9 используется формула

```text
demand(q) = q_base_demand − price_sensitivity × (price − base_price)
predicted_sales = min(seats, max(0, demand(0.5)))
```

Спрос может быть отрицательным. Продажи ограничены нулём и вместимостью рейса.
Цена должна быть конечным положительным JSON-числом с точностью до копейки.
Ошибочный ввод возвращает HTTP 422, отсутствие рейса — HTTP 404.

Все поля ответа и форма для отправки запросов доступны в
[документации API](http://127.0.0.1:8000/docs) после запуска сервера.

## Подключение собственного прогноза

Справочник маршрутов находится в data/routes.csv, итоговый прогноз по умолчанию —
в data/ПоповАлександрМаксимович_my_forecast.csv. Официальный
seasonal_forecast.csv сохранён как резервный вариант. Файл прогноза должен содержать route, date,
seats и девять столбцов от 0.1_base_demand до 0.9_base_demand.
Дата записывается как YYYY-MM-DD, пара route и date должна быть уникальной,
маршрут должен присутствовать в справочнике. Число мест — целое неотрицательное,
значения квантилей — конечные и неубывающие.

Положите свой CSV в data/ и задайте его имя перед запуском.

```powershell
$env:FORECAST_FILENAME = "seasonal_forecast.csv"
.\.venv\Scripts\python.exe -m uvicorn backend.main:app
```

Данные читаются при старте, поэтому после замены CSV перезапустите сервер.
Имя используемого файла показано в карточке результата. Для возврата к
итоговому прогнозу удалите переменную FORECAST_FILENAME, а для переключения
на официальный сезонный прогноз задайте ей значение seasonal_forecast.csv.

## Размещение на сервере

Рабочий каталог — корень репозитория. Установите Python-зависимости из
requirements.txt и выполните npm ci и npm run build в frontend/.
Сохраните каталог frontend/dist/browser вместе с backend и data.

Команда запуска для Linux-хостинга с переменной PORT

```sh
python -m uvicorn backend.main:app --host 0.0.0.0 --port "$PORT"
```

FastAPI раздаёт собранную страницу и API с одного адреса.
